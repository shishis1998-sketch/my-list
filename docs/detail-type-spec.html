调的时候注意三件事

一、别写死 px。每一级都是 calc(N px × var(--fs-scale))，设置里的「小 / 中 / 大」靠它整梯缩放。写死之后那一处就不跟着变了。

二、行高只有三档：--lh-tight 1.3（书名）、--lh-normal 1.45（默认）、--lh-loose 1.6（备注）。别新增第四档。

三、图形尺寸不算字号。主题色短线 26×2、时间条高 4、标签胶囊高 22、分隔线 1px 都是画出来的形状，不跟字号阶梯缩放（标签胶囊在「大」档单独长到 26，否则字会把胶囊塞满）。

图中数值 = index.html 现状（.dt-* 段落 + :root 字号阶梯）。手机档 --fs-body 是 15，电脑档 14——这是全站唯一一处手机比电脑大的字号，备注正文因此在手机上更好读。跟随系统深浅色。
