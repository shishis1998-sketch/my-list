改之前先知道这几条

GRID

四行是一整套 grid-template-areas：name/watch → cat/status/score → note → tags/acts。挪格子要连着 areas 一起改。封面列已经整列去掉，现在只有三列。

GAP

行距只有一个 gap: 6 管全部四行。想单独拉开某两行别动 gap，给那一格加 margin-top——备注行就是这么干的（线上 4、线下 8）。

COL

右栏宽度 73.2 是被日期 2026/8/12 撑出来的，评分、「收起」都跟着它走。日期换回中文写法（2026年8月12日 ≈ 100）会把标题挤到第二行。

FONT

字号都走 --fs-* 三档：15（--fs-body，标题/备注/评分）、13（--fs-caption，作者/时间/胶囊）、11（--fs-foot，状态）。设置页的「字号 小/中/大」是乘 --fs-scale，所以改 token 会整站跟着动；只想改卡片就改具体选择器。

EMPTY

没填时间 / 没打标签的行，那两格是 display:none（nowatch / notags）。但没写备注的行仍会画一条分隔线加一个「—」，占掉 33——图 3 第一张卡底部那块就是它。
