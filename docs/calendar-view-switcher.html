视图切换：从顶部胶囊条，搬到底部抽屉

现在「日历 / 经期 / 年度 / 标签」是一条常驻在日历页最顶上的四段胶囊条（.cal-vtoggle.cvt4）， 一年到头占着一整行，而真正会切换的频率很低。改法：这行去掉，改成在日历页里再点一次底栏的「日历」tab，从底部弹出一张选择面板—— 手指本来就在底栏，切换动作离手最近。

参考的是 Outlook 点「应用」弹出的那张底部面板，但不照抄它的方形图标九宫格。下面五版都是非方形的形态， 分别把重点放在「说得清」「够紧凑」「零新组件」上，可以直接挑一版落地。

问题一 · 常驻但低频。切视图一天可能只发生一两次，胶囊条却全天占着首屏最贵的那一行（连上下间距共 50px）。

问题二 · 挤。四段等分后每段净宽约 68px，「日历」两字加上下 4px padding 已经贴边，再加一档就放不下了。

问题三 · 够不着。它在屏幕最顶端，而人的拇指常年停在底栏；每次切换都要伸手到顶。

问题四 · 语义重复。底栏已经有一个「日历」tab 亮着，顶部又有一个「日历」段亮着，同一个词在一屏里高亮两次。

五个方案

AFTER · 甲乙丙丁戊

五版共用同一个触发：人已经在日历页时，再点一次底栏「日历」tab（不在日历页时这个 tab 还是老行为——进日历）。 遮罩只压内容区，底栏本身不变暗，手指仍能看见自己刚点的位置。

甲说明式列表

日历月历格 + 当天的记录
经期周期预测与症状记录
年度一整年热力，一屏看完
标签按症状标签分组的月历

整屏宽的抽屉，一行一个视图：图标 + 名字 + 一句话说明，当前项打勾。 「经期」「标签」这种光看名字猜不透的视图，副标题正好补上。

代价　高约 250px（占屏 46%），是五版里最占地方的；四个视图不算多，说明文字读一次就不再需要。

乙紧凑列表

切换视图

同一张抽屉去掉说明文字，行高压到 40px，发丝线分隔，当前项整行铺淡绿底。 形态跟现有的排序 / 筛选抽屉是同一套，读起来像 App 里本来就有的东西。

代价　高约 210px，仍会盖住三分之一屏；名字之外没有任何解释。

丙胶囊横排

就是把原来顶部那条胶囊原封不动挪到底栏正上方，只在需要时出现。 高度只有约 60px，几乎不遮日历；不用遮罩，点外面任意处收起。

代价　每段还是那么窄，视图再多一档就要横向滚动；出现时把底栏「垫高」了一层，视觉上有点像双层导航。

丁宽磁贴 2×2

切换视图

参考图那种面板的骨架，但磁贴是横向的圆角矩形——图标在左、文字在右，不是方块套文字。 两列四块正好填满，四个入口一眼扫完，点击面积也最大。

代价　2×2 网格没有顺序感，而这四个视图其实是有主次的（日历是家）；再加第五档就得排成不齐整的 2+3。

戊贴着 tab 的小卡片

＝ 现成的 .bb-sortpanel

不是抽屉，是一张从「日历」tab 头上长出来的小卡片，宽度只由最长那项决定。 这正是 App 里排序 / 筛选已经在用的 .bb-sortpanel：同一套圆角、阴影、弹入动画、选中高亮， 零新组件、零新样式，只是换个锚点和一份数据。

推荐　最省改动、最像原生；小箭头明确指出「这是刚才那个 tab 弹的」，解决了顶部条「两个日历同时高亮」的重复。

建议

NEXT

SHIPPED · 已按 戊 落地

先落 戊，它几乎是白捡的

排序和筛选那两张小卡片（.bb-sortsheet + .bb-sortpanel + placeBBPanel）已经把 「贴着底栏某个按钮上方弹出、点外面收起、选中项高亮」整套做完了。视图切换只需要多喂一份四行的数据， 把锚点从排序按钮换成 #bbtab-cal，再给卡片补一个指向 tab 的小箭头。

  1. 删掉 .cal-viewbar 整行（.cal-vtoggle.cvt4 及其 .cvt-thumb 相关样式），日历页首屏立刻多出 50px。
  2. openCalendar() 改成：已经在日历页时不重复进入，转而弹出视图卡片；不在日历页时行为不变。
  3. 底栏「日历」tab 的文字跟着当前视图走（在经期视图时就显示「经期」），这样底栏本身成了「现在在哪个视图」的指示器，顶部那个重复高亮的问题自然消失。
  4. setCalView() 内部不动，只是把调用方从胶囊段换成卡片行。

如果更希望「一眼看懂每个视图是干嘛的」——尤其是「标签」这个名字确实不自解释——那就选甲， 代价是每次切换都要盖掉半屏。想要最不打扰、切换最快，就选丙。

落地后的两处调整：①卡片宽度收到 96px（比这张示意图还窄一档，宽度只够「两个字 + 图标」， 贴着 tab 更像是从它长出来的）；②顶部那条四段胶囊只在手机端收起——桌面端没有底栏， 那边仍靠它切换，两套共用同一个 setCalView() 和同一份「上次停在哪个视图」的记忆。
